यह consent-based location sharing demo है।
1. Node.js install करें।
2. इस folder में terminal खोलें और: npm install
3. फिर: npm start
4. अपने browser में http://localhost:3000 खोलें।
5. /view पेज latest shared location दिखाता है।

इसे public link बनाने के लिए किसी Node.js hosting service पर deploy करें।
महत्वपूर्ण: user को स्पष्ट रूप से बताएं कि location share होगी और browser permission स्वयं allow करनी होगी।
